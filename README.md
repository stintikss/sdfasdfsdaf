# FinBot — личный бухгалтер в Telegram

Первая рабочая версия личного финансового бота на Python + aiogram 3 + PostgreSQL. Данные хранятся в PostgreSQL, поэтому не пропадают при перезапуске Render.

## Важно перед запуском

Токен, который был отправлен в переписку, нужно отозвать в `@BotFather` (`/mybots` → бот → API Token → Revoke) и использовать новый. Никогда не вставляй токен в `bot.py` и не загружай `.env` в GitHub.

## Что уже есть

- 📊 Дашборд капитала: RUB, USD, пересчёт по заданному вручную курсу, ориентировочные проценты.
- 🏦 Активы: карта/наличные, накопительный счёт, вклад, ЦФА, прочее; валюта, ставка, дата погашения; пополнение, снятие, закрытие.
- 💸 Журнал доходов и расходов с валютой, категорией и комментарием.
- 🎯 Цели с суммой, дедлайном и расчётом требуемого темпа накоплений.
- 📈 Аналитика за 30 дней и примерный прогноз начислений.
- 📑 История последних операций.
- 💡 Пожелания: записывать идеи, отмечать выполненными и удалять.
- ⚙️ Настройки ручного курса USD/RUB и отображения долларового эквивалента.
- ❔ Встроенная инструкция.
- Кнопки «Назад» и «Главное меню» в разделах.
- Ограничение по Telegram ID, если задать `OWNER_ID`.

## Что важно знать

- Бот не подключается к банкам или UNU автоматически — доходы и балансы нужно вводить вручную.
- USD/RUB курс задаётся вручную и не обновляется автоматически.
- Доходность считается упрощённо как ставка / 365. Реальные вклады, накопительные счета и ЦФА могут иметь капитализацию, лимиты, налоги, купоны и особые правила.
- В этой версии переводы между активами не имеют отдельного мастера, а прогресс целей пока не пополняется отдельной операцией. Эти функции можно добавить следующей итерацией.
- Напоминания — заглушка-раздел; для расписания понадобится APScheduler/планировщик и постоянно работающий worker.
- `DASHBOARD_IMAGE_URL` позволяет добавить публичную HTTPS-картинку к дашборду. Оставь пустым, чтобы дашборд был текстовым. Можно использовать собственную иллюстрацию без личных банковских данных.

## Подготовка GitHub

1. Создай пустой репозиторий.
2. Загрузи `bot.py`, `requirements.txt`, `render.yaml`, `.gitignore`, `.env.example`, `README.md`.
3. Не загружай `.env` и настоящий токен.
4. Если токен уже попал в репозиторий — удали его из истории недостаточно: сначала отзови токен в BotFather.

## PostgreSQL и Render

1. Создай PostgreSQL у провайдера, например Neon или Supabase, и скопируй connection string с SSL.
2. На Render создай **Background Worker**, подключи GitHub-репозиторий.
3. Build command: `pip install -r requirements.txt`
4. Start command: `python bot.py`
5. В Environment добавь:
   - `BOT_TOKEN` — новый токен из BotFather
   - `OWNER_ID` — твой числовой Telegram ID (узнать командой `/id` после запуска без ограничения или через собственного ID-бота; лучше временно поставить `0`, получить ID, затем обязательно заменить)
   - `DATABASE_URL` — строка подключения PostgreSQL
   - `USD_RUB_RATE` — ориентировочный курс для старта
   - `DASHBOARD_IMAGE_URL` — необязательно, публичный HTTPS URL изображения
6. Deploy. Открой бота в Telegram и отправь `/start`.

## Порядок первого запуска

1. Временно выставь `OWNER_ID=0`, если не знаешь свой ID.
2. После деплоя отправь `/id` и запиши число.
3. Останови worker, выставь `OWNER_ID` равным этому числу и запусти заново.
4. Добавь активы, затем проверь дашборд и историю.

## Безопасность

Это личный трекер, а не банковское приложение. Не добавляй номера карт, CVV, пароли, коды подтверждения или секретные данные в заметки. Для публичного GitHub токен хранится только в Render Environment.
